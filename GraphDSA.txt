### **1. Key Graph Concepts**

A **graph** consists of nodes (vertices) and edges that connect these nodes. Graphs can be **directed** or **undirected**, **weighted** or **unweighted**.

#### **a) Types of Graphs**

* **Directed Graph (Digraph)**: Edges have a direction, meaning they go from one vertex to another.
* **Undirected Graph**: Edges don’t have a direction; they connect two vertices both ways.
* **Weighted Graph**: Each edge has a weight or cost associated with it.
* **Unweighted Graph**: All edges are equal, and the focus is on connectivity rather than the edge costs.

#### **b) Graph Representations**

* **Adjacency Matrix**: A 2D array where `matrix[i][j] = 1` if there's an edge between vertex `i` and `j`. It uses O(V^2) space.
* **Adjacency List**: A list where each node has a list of connected nodes. It is more space-efficient (O(V + E) space).

#### **c) Traversal Algorithms**

* **Depth-First Search (DFS)**: Explores as far down a branch as possible before backtracking. It's often used for exploring all nodes in a graph, pathfinding, and topological sorting.
* **Breadth-First Search (BFS)**: Explores all neighbors at the present depth level before moving on to nodes at the next depth level. It's useful for shortest path finding in unweighted graphs.

### **2. Common Graph Algorithms and Patterns**

#### **a) Depth-First Search (DFS)**

DFS is typically used for **exploring all nodes** of a graph or tree, **pathfinding**, **detecting cycles**, and **topological sorting**.

* **Use Cases**:

  * **Finding connected components** in a graph.
  * **Cycle detection** in directed and undirected graphs.
  * **Topological sorting** for Directed Acyclic Graphs (DAGs).

**Example Problems**:

* **Number of Connected Components in an Undirected Graph** (LeetCode #323)
* **Course Schedule** (LeetCode #207)
* **Cycle in a Directed Graph** (LeetCode #207)

#### **b) Breadth-First Search (BFS)**

BFS is often used for **shortest path algorithms** in unweighted graphs, **finding connected components**, and **level-order traversal** of a graph.

* **Use Cases**:

  * **Shortest path in unweighted graphs**.
  * **Level-order traversal**.
  * **Finding the number of islands** in a grid representation of a graph.

**Example Problems**:

* **Number of Islands** (LeetCode #200)
* **Word Ladder** (LeetCode #127)
* **Minimum Depth of Binary Tree** (LeetCode #111)

#### **c) Dijkstra's Algorithm**

Dijkstra's algorithm finds the **shortest path** from a source node to all other nodes in a **weighted graph**.

* **Use Cases**:

  * **Shortest path** in a weighted graph.
  * **Routing problems** in networks.

**Example Problems**:

* **Dijkstra's Shortest Path Algorithm** (LeetCode #743)
* **Network Delay Time** (LeetCode #743)

#### **d) Bellman-Ford Algorithm**

The **Bellman-Ford algorithm** is used to find the shortest paths from a single source to all other vertices in a **weighted graph** and can handle negative edge weights.

* **Use Cases**:

  * Detect **negative weight cycles**.
  * **Shortest path** in graphs with negative weights.

**Example Problems**:

* **Bellman-Ford Algorithm** (LeetCode #787)

#### **e) Floyd-Warshall Algorithm**

Floyd-Warshall is an **all-pairs shortest path algorithm**. It finds the shortest paths between all pairs of vertices in a weighted graph.

* **Use Cases**:

  * Finding shortest paths between all pairs of nodes.
  * Handling graphs with negative weights (without negative cycles).

**Example Problems**:

* **Shortest Path in a Graph** (LeetCode #399)
* **All Pairs Shortest Path** (LeetCode #785)

#### **f) Topological Sort**

Topological sorting is used on **Directed Acyclic Graphs (DAGs)**. It’s a linear ordering of vertices such that for every directed edge `uv`, vertex `u` comes before `v` in the ordering.

* **Use Cases**:

  * **Task scheduling** or **build ordering**.
  * **Course prerequisites**.

**Example Problems**:

* **Course Schedule II** (LeetCode #210)
* **Alien Dictionary** (LeetCode #269)

#### **g) Cycle Detection**

* **DFS-based cycle detection**: We can detect cycles in a **directed** or **undirected** graph using DFS with backtracking.
* **Union-Find cycle detection**: This is another way to detect cycles in **undirected graphs** by tracking connected components and checking if a node already belongs to the same component.

**Example Problems**:

* **Course Schedule** (LeetCode #207) - Detect cycle in a directed graph.
* **Graph Valid Tree** (LeetCode #261) - Detect cycle in an undirected graph.

#### **h) Union-Find (Disjoint Set Union - DSU)**

Union-Find is a data structure that helps in efficiently handling **dynamic connectivity problems**. It supports two key operations: **union** and **find**.

* **Use Cases**:

  * **Connected components**.
  * **Cycle detection** in undirected graphs.
  * **Kruskal's Minimum Spanning Tree (MST)** algorithm.

**Example Problems**:

* **Number of Connected Components in an Undirected Graph** (LeetCode #323)
* **Accounts Merge** (LeetCode #721)

#### **i) Kruskal's Algorithm**

Kruskal's algorithm is used to find the **Minimum Spanning Tree (MST)** of a graph. It works by adding edges in increasing order of weight while ensuring no cycles are formed.

* **Use Cases**:

  * **MST** (minimum spanning tree) in a weighted graph.
  * **Network design** (like connecting computers with minimal cost).

**Example Problems**:

* **Kruskal's Algorithm** (LeetCode #1135)

#### **j) Prim's Algorithm**

Prim's algorithm is another way to find the **Minimum Spanning Tree (MST)**, but it starts with a single vertex and expands the MST by adding edges that have the smallest weight.

**Example Problems**:

* **Minimum Cost to Connect All Points** (LeetCode #1584)

### **4. Practice Suggestions for Graphs**

* **Master graph traversal**: Start with **BFS** and **DFS**, and get comfortable with their iterative and recursive implementations.
* **Solve pathfinding problems**: Implement **Dijkstra's**, **Bellman-Ford**, and **Floyd-Warshall** algorithms.
* **Topological Sort**: Understand how to perform **topological sorting** in DAGs and how to detect cycles.
* **Union-Find**: Learn how to implement the **Union-Find** data structure for cycle detection and connected components.
* **Minimum Spanning Tree**: Practice **Kruskal’s** and **Prim’s** algorithms for finding the MST.
* **Practice with grid-based problems**: Many graph problems are represented as 2D grids, such as finding islands or the shortest path in a maze.
