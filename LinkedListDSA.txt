### **1. Key Linked List Patterns to Recognize**

#### **a) Slow and Fast Pointers (Floyd’s Cycle Detection)**

This pattern is used for problems where you need to detect **cycles** or find a **middle element** in a linked list.

* **Problem Types**:

  * Detect if a linked list has a cycle (Floyd’s Cycle-Finding Algorithm).
  * Find the start of the cycle in a linked list.
  * Find the middle element of a linked list.
  * Find the intersection point of two linked lists.

* **How It Works**:

  * Use two pointers: **slow** and **fast**. The slow pointer moves one step at a time, and the fast pointer moves two steps at a time. If there is a cycle, they will meet at some point. If not, the fast pointer will reach the end.

* **Example Problems**:

  * **Linked List Cycle** (LeetCode #141)
  * **Find the Middle of the Linked List** (LeetCode #876)
  * **Intersection of Two Linked Lists** (LeetCode #160)

#### **b) Reversing a Linked List**

Reversing a linked list is a fundamental problem, and you should be able to do it iteratively and recursively.

* **Problem Types**:

  * Reverse a singly linked list.
  * Reverse a portion of a linked list (a sublist).
  * Reverse the second half of a linked list.

* **How It Works**:

  * **Iterative Approach**: Traverse the list and reverse the direction of the links between the nodes.
  * **Recursive Approach**: Reverse the rest of the list first and then adjust the pointers.

* **Example Problems**:

  * **Reverse Linked List** (LeetCode #206)
  * **Reverse Linked List II** (LeetCode #92)

#### **c) Merge Two Linked Lists**

In this pattern, we merge two sorted linked lists into a single sorted list.

* **Problem Types**:

  * Merge two sorted linked lists.
  * Merge K sorted linked lists.
* **How It Works**:

  * Use a dummy node to simplify the merging process. Traverse both lists, comparing nodes one by one, and connect the smaller node to the merged list.
* **Example Problems**:

  * **Merge Two Sorted Lists** (LeetCode #21)
  * **Merge k Sorted Lists** (LeetCode #23)

#### **d) Two-Pointer Approach**

Used to compare nodes at two different positions or parts of the linked list. Often used to solve problems like finding the **k-th node from the end** or determining if a linked list is a **palindrome**.

* **Problem Types**:

  * Find the **k-th node from the end**.
  * Check if the linked list is a **palindrome**.
  * Check if two linked lists intersect.

* **How It Works**:

  * Move one pointer **k steps ahead**, then start the second pointer from the beginning. When the first pointer reaches the end, the second pointer will be at the k-th node from the end.

* **Example Problems**:

  * **Nth Node from End of Linked List** (LeetCode #19)
  * **Palindrome Linked List** (LeetCode #234)

#### **e) Partitioning Linked List**

Partition a linked list around a value **x** such that all nodes less than **x** come before all nodes greater than or equal to **x**.

* **Problem Types**:

  * Partition the linked list based on a value.
  * Reorder the list in a specific way.

* **How It Works**:

  * Traverse the list and maintain two separate lists: one for values less than **x** and one for values greater than or equal to **x**. After traversing the list, merge both lists.

* **Example Problems**:

  * **Partition List** (LeetCode #86)

#### **f) Deleting Nodes**

Deleting specific nodes from a linked list is another important pattern, especially in problems that require in-place modification.

* **Problem Types**:

  * Delete a node from a linked list given access to that node.
  * Remove duplicates from an unsorted linked list.

* **How It Works**:

  * For deleting a specific node (not the head), you can simply copy the value of the next node into the current node and delete the next node. For duplicates, you can use a **hash set** to keep track of seen values.

* **Example Problems**:

  * **Delete Node in a Linked List** (LeetCode #237)
  * **Remove Duplicates from Sorted List** (LeetCode #83)

### **2. Key Algorithms for Linked Lists**

#### **a) Reversing a Linked List (Iterative and Recursive)**

Reversing a linked list is one of the most fundamental linked list operations.

* **Iterative Approach**:

  * Traverse the list, reversing the next pointer of each node.
* **Recursive Approach**:

  * Reverse the rest of the list first, and then update the current node’s next pointer.

```python
# Iterative Approach
def reverse_linked_list(head):
    prev = None
    curr = head
    while curr:
        next_node = curr.next
        curr.next = prev
        prev = curr
        curr = next_node
    return prev

# Recursive Approach
def reverse_linked_list_recursive(head):
    if not head or not head.next:
        return head
    rest = reverse_linked_list_recursive(head.next)
    head.next.next = head
    head.next = None
    return rest
```

#### **b) Cycle Detection (Floyd’s Tortoise and Hare)**

You can use **two pointers**, one moving twice as fast as the other, to detect cycles.

```python
def has_cycle(head):
    slow, fast = head, head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False
```

#### **c) Merging Two Sorted Linked Lists**

You can merge two sorted linked lists in O(n) time by comparing nodes and attaching them in sorted order.

```python
def merge_two_lists(l1, l2):
    dummy = ListNode(0)
    current = dummy
    while l1 and l2:
        if l1.val < l2.val:
            current.next = l1
            l1 = l1.next
        else:
            current.next = l2
            l2 = l2.next
        current = current.next
    current.next = l1 if l1 else l2
    return dummy.next
```

### **5. Advanced Topics for Linked Lists**

Once you're comfortable with the basics, you can explore more advanced topics like:

* **Skip Lists**: A probabilistic data structure that allows for faster search times.
* **Doubly Linked Lists**: Where each node points to both the next and the previous node.
* **Circular Linked Lists**: A variant where the last node points back to the head node.
