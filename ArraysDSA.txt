
### **Arrays: Important Patterns & Algorithms to Master**

#### **1. Basic Operations:**

Before diving into complex problems, make sure you're comfortable with basic array operations:

* **Traversal**: Iterating through arrays to print or check values.
* **Insertion**: Adding elements to the array at specific indices.
* **Deletion**: Removing elements from specific indices.
* **Searching**: Linear search and binary search.

#### **2. Key Patterns to Recognize:**

##### **a) Two Pointer Pattern**

This is a very popular pattern, especially for problems that involve **sorting** or **subarrays**.

* **Problem Types**:

  * **Pair Sum**: Find two numbers in the array that sum to a given value (e.g., two-sum problem).
  * **Triplet Sum**: Find triplets that sum to a specific value.
  * **Rearrange array**: Arrange elements in a certain order (e.g., move all negative elements to one side).

* **How It Works**:
  You have two pointers: one starting from the beginning of the array and the other from the end.

  * If the sum of the two elements pointed to by the pointers is greater than the target, move the right pointer left.
  * If the sum is smaller, move the left pointer right.
  * If you find a pair, check for the next possible pair.

* **Example Problems**:

  * **Two Sum** (LeetCode #1)
  * **3Sum** (LeetCode #15)
  * **Container With Most Water** (LeetCode #11)

##### **b) Sliding Window Pattern**

This is a great pattern for problems involving **subarrays** or **substring** manipulation, especially when you need to find the **maximum** or **minimum** sum, length, etc., within a contiguous segment of the array.

* **Problem Types**:

  * **Maximum Sum Subarray of Size K**: Find the sum of any subarray of size K.
  * **Longest Substring Without Repeating Characters**: Find the longest substring with distinct characters.
  * **Subarray with Given Sum**: Find a subarray whose sum equals a given target.
* **How It Works**:

  * You maintain a window of fixed or dynamic size that you slide across the array.
  * You add elements to the window and move the window to the right, adjusting the size or sum based on the problem requirements.
* **Example Problems**:

  * **Maximum Subarray Sum of Size K** (LeetCode #239)
  * **Longest Substring Without Repeating Characters** (LeetCode #3)
  * **Subarray Sum Equals K** (LeetCode #560)

##### **c) Fast & Slow Pointer (Tortoise & Hare)**

This pattern is useful for problems that require you to **detect cycles** or **find the middle** of the array or linked list.

* **Problem Types**:

  * **Detecting Cycles**: Checking if there is a cycle in an array (often used for linked list cycle detection).
  * **Middle Element**: Finding the middle element of an array (or a linked list).
  * **Happy Number**: A number is considered happy if, repeatedly replacing the number with the sum of the squares of its digits, it eventually becomes 1.

* **How It Works**:

  * You use two pointers, one moving at twice the speed of the other. If there’s a cycle, the fast pointer will eventually meet the slow pointer.

* **Example Problems**:

  * **Linked List Cycle** (LeetCode #141)
  * **Happy Number** (LeetCode #202)

##### **d) Sorting**

A good grasp of **sorting algorithms** is crucial for many array-related problems. Sorting can help simplify problems where the array’s order matters.

* **Key Algorithms to Know**:

  * **Bubble Sort**: Not very efficient but useful for learning basic sorting concepts.
  * **Insertion Sort**: Good for small or partially sorted arrays.
  * **Quick Sort**: Average O(n log n) time complexity, very efficient.
  * **Merge Sort**: Also O(n log n) but uses extra space for splitting.
  * **Cyclic Sort**: Also O(n).
  * **Counting Sort**: Efficient for smaller integer ranges (works in linear time).
  

* **Example Problems**:

  * **Sort Colors** (LeetCode #75)
  * **Find Kth Largest Element** (LeetCode #215)
  * **Merge Intervals** (LeetCode #56)

##### **e) Partitioning**

This is useful when you're asked to **divide** an array into parts based on certain conditions.

* **Problem Types**:

  * **Partitioning Around Pivot**: Partition the array based on a pivot element (used in QuickSort).
  * **Dutch National Flag Problem**: Sort an array with three distinct values.

* **How It Works**:

  * You rearrange elements around a certain value or pivot.

* **Example Problems**:

  * **Dutch National Flag Problem** (LeetCode #75)
  * **QuickSort** (LeetCode #215)

### **3. Key Algorithms to Master**

#### **a) Binary Search**

Binary search is a key technique for efficiently searching sorted arrays. It works by repeatedly dividing the search range in half.

* **Time Complexity**: O(log n)
* **Use Cases**:

  * **Search in a sorted array**
  * **Find the first/last occurrence of an element**
  * **Find the insertion point for an element**
* **Example Problems**:

  * **Binary Search** (LeetCode #704)
  * **Find First and Last Position of Element in Sorted Array** (LeetCode #34)

#### **b) Kadane's Algorithm**

This is a dynamic programming-based approach to finding the **maximum sum subarray**.

* **Time Complexity**: O(n)
* **Use Case**:

  * **Maximum Subarray Sum** (find the contiguous subarray with the largest sum)
* **Example Problems**:

  * **Maximum Subarray** (LeetCode #53)

#### **c) Prefix Sum / Cumulative Sum**

This technique helps you to quickly calculate the sum of elements in any subarray by storing cumulative sums.

* **Time Complexity**: O(n) for preprocessing the array
* **Use Case**:

  * **Find the sum of elements in any subarray**
  * **Prefix sum for efficient range queries**
* **Example Problems**:

  * **Subarray Sum Equals K** (LeetCode #560)
  * **Range Sum Query** (LeetCode #303)
