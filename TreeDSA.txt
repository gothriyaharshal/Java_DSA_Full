### **1. Key Tree Patterns and Algorithms**

#### **a) Binary Tree Traversals**

Traversing a tree is one of the most fundamental problems. We have three common types of traversal:

* **Preorder Traversal (NLR)**: Visit the node first, then left, then right.

* **Inorder Traversal (LNR)**: Visit the left node first, then the node, then right.

* **Postorder Traversal (LRN)**: Visit the left node first, then right, then the node.

* **Level Order Traversal (BFS)**: Traverse the tree level by level using a queue.

**Example Problems**:

* **Binary Tree Inorder Traversal** (LeetCode #94)
* **Binary Tree Preorder Traversal** (LeetCode #144)
* **Binary Tree Postorder Traversal** (LeetCode #145)
* **Binary Tree Level Order Traversal** (LeetCode #102)

#### **b) Depth-First Search (DFS)**

DFS explores as far down a branch as possible before backtracking. It's commonly implemented using recursion.

* **Use Cases**:

  * Finding a path in a tree.
  * Solving problems like finding **diameter** or **height** of a tree.

* **Types of DFS**:

  * **Preorder DFS**: Visit node, then left, then right.
  * **Postorder DFS**: Visit left, then right, then node.
  * **Inorder DFS**: Visit left, then node, then right.

**Example Problems**:

* **Maximum Depth of Binary Tree** (LeetCode #104)
* **Diameter of Binary Tree** (LeetCode #543)

#### **c) Breadth-First Search (BFS)**

BFS explores a tree level by level, making it ideal for problems like finding the **shortest path** in a tree.

* **Use Cases**:

  * Level order traversal of a tree.
  * Finding the **shortest path** in an unweighted tree.

* **Implementation**: BFS is often implemented using a **queue**.

**Example Problems**:

* **Binary Tree Level Order Traversal** (LeetCode #102)
* **Zigzag Level Order Traversal** (LeetCode #103)

#### **d) Binary Search Tree (BST) Operations**

A **Binary Search Tree (BST)** is a special type of binary tree where the left subtree of a node contains only nodes with values smaller than the node, and the right subtree contains only nodes with values greater than the node.

* **Key Operations**:

  * **Insert**: Add a node to the tree while maintaining the BST property.
  * **Search**: Find a value in the tree.
  * **Delete**: Remove a node and restructure the tree to maintain the BST property.

**Example Problems**:

* **Validate Binary Search Tree** (LeetCode #98)
* **Insert into a Binary Search Tree** (LeetCode #701)
* **Delete Node in a BST** (LeetCode #450)

#### **e) Lowest Common Ancestor (LCA)**

The **Lowest Common Ancestor (LCA)** of two nodes in a tree is the deepest node that is an ancestor of both nodes.

* **Use Cases**:

  * Find the **LCA** of two nodes in a binary tree or BST.

**Example Problems**:

* **Lowest Common Ancestor of a Binary Search Tree** (LeetCode #235)
* **Lowest Common Ancestor of a Binary Tree** (LeetCode #236)

#### **f) Tree Diameter**

The **diameter** of a tree is the length of the longest path between two nodes in the tree.

* **Use Case**: This is often used to find the longest path in a tree, which could be critical for problems related to network design or graph traversal.

**Example Problem**:

* **Diameter of Binary Tree** (LeetCode #543)

#### **g) Binary Tree Maximum Path Sum**

The **maximum path sum** is the largest sum of values that can be obtained by starting at any node and following the path to any other node.

* **Use Case**: This problem can be related to dynamic programming in trees.

**Example Problem**:

* **Binary Tree Maximum Path Sum** (LeetCode #124)

#### **h) Serialize and Deserialize a Binary Tree**

Serialization refers to converting a tree to a string representation, and deserialization refers to reconstructing the tree from the string.

* **Use Case**: This can be useful for storing and transmitting trees, e.g., for databases or distributed systems.

**Example Problem**:

* **Serialize and Deserialize Binary Tree** (LeetCode #297)

### **2. Common Tree Patterns to Recognize**

#### **a) Symmetric Tree**

A symmetric tree is a tree that is a mirror image of itself.

* **How to Solve**:

  * Use recursion to compare the left and right subtrees of each node to check if they are mirror images of each other.

**LeetCode Problem**:

* **Symmetric Tree** (LeetCode #101)

#### **b) Balanced Binary Tree**

A tree is balanced if the height of the two subtrees of every node differ by no more than 1.

* **How to Solve**:

  * Use a DFS approach to calculate the height of the subtrees while checking if the difference in heights is greater than 1.

**LeetCode Problem**:

* **Balanced Binary Tree** (LeetCode #110)

#### **c) Path Sum**

Given a binary tree and a sum, determine if there is a root-to-leaf path that sums to the given value.

* **How to Solve**:

  * Use a DFS traversal to calculate the sum of each path and check if it matches the target sum.

**LeetCode Problem**:

* **Path Sum** (LeetCode #112)
* **Path Sum II** (LeetCode #113)

#### **d) Convert Sorted Array to Binary Search Tree**

Given a sorted array, construct a **height-balanced** binary search tree.

* **How to Solve**:

  * Recursively find the middle element of the array and use it as the root. This will help in constructing a balanced BST.

**LeetCode Problem**:

* **Convert Sorted Array to Binary Search Tree** (LeetCode #108)

#### **e) Construct Binary Tree from Preorder and Inorder Traversal**

Given **preorder** and **inorder** traversals of a binary tree, construct the binary tree.

* **How to Solve**:

  * Use the preorder traversal to get the root of the tree, and use the inorder traversal to separate the left and right subtrees.

**LeetCode Problem**:

* **Construct Binary Tree from Preorder and Inorder Traversal** (LeetCode #105)
