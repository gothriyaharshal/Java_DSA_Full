### **1. String Patterns to Recognize**

#### **a) Sliding Window Pattern (Substrings)**

The sliding window pattern is especially useful when you need to find a **substring** or a **substring with certain properties**.

* **Problem Types**:

  * Find the longest substring with distinct characters.
  * Find the smallest substring containing all characters of another string.
  * Check if a substring exists that satisfies a certain condition (like sum, count, etc.).

* **How It Works**:

  * Maintain a window of characters from the string and adjust the window size dynamically.
  * Move the right pointer to expand the window and the left pointer to shrink it while keeping track of the required properties (like length or distinct characters).

* **Example Problems**:

  * **Longest Substring Without Repeating Characters** (LeetCode #3)
  * **Minimum Window Substring** (LeetCode #76)
  * **Substring with Concatenation of All Words** (LeetCode #30)

#### **b) Two Pointer Pattern**

Similar to the two-pointer pattern in arrays, it is used in strings to compare characters from both ends.

* **Problem Types**:

  * Check if a string is a palindrome.
  * Reverse a string.
  * Find the longest common subsequence between two strings.
* **How It Works**:

  * Start from both ends of the string, compare characters, and gradually move toward the middle.
* **Example Problems**:

  * **Valid Palindrome** (LeetCode #125)
  * **Reverse String** (LeetCode #344)

#### **c) Greedy / Backtracking (Subsequences and Substrings)**

Some problems, especially those involving finding substrings or subsequences, can be approached with **greedy algorithms** or **backtracking**.

* **Problem Types**:

  * Find the longest common subsequence between two strings.
  * Find the longest increasing subsequence.
  * Generate all possible subsequences or substrings.

* **How It Works**:

  * **Greedy**: Choose the optimal solution at each step (e.g., matching characters in subsequences).
  * **Backtracking**: Try all possible combinations and prune invalid ones (e.g., generating subsequences).

* **Example Problems**:

  * **Longest Common Subsequence** (LeetCode #1143)
  * **Generate Parentheses** (LeetCode #22)

#### **d) Dynamic Programming (Edit Distance)**

Dynamic programming (DP) is often used for **string transformation** problems where we need to find the minimum number of operations (like insertions, deletions, or substitutions) to transform one string into another.

* **Problem Types**:

  * Find the minimum edit distance between two strings.
  * Find the longest common substring.

* **How It Works**:

  * Break the problem into smaller subproblems and build up the solution using previously solved subproblems.

* **Example Problems**:

  * **Edit Distance** (LeetCode #72)
  * **Longest Palindromic Subsequence** (LeetCode #516)

### **2. Key String Algorithms to Master**

#### **a) KMP (Knuth-Morris-Pratt) Algorithm**

The KMP algorithm is used for **pattern matching**. It searches for occurrences of a pattern within a text in **O(n)** time.

* **Time Complexity**: O(n + m) (where n is the length of the text and m is the length of the pattern).

* **Use Case**: Searching for a substring or pattern within a string.

* **Example Problems**:

  * **Implement strStr()** (LeetCode #28) — Find the index of the first occurrence of a substring.

#### **b) Rabin-Karp Algorithm**

This is another **pattern matching** algorithm that uses hashing to compare substrings.

* **Time Complexity**: O(n + m) for average cases, though worst-case is O(n\*m).
* **Use Case**: Checking for the presence of a pattern or substring in a string using hash values.

#### **c) Z Algorithm**

The Z algorithm calculates the **Z-array** for a string, which helps with pattern matching and finding the longest prefix that matches a substring.

* **Time Complexity**: O(n)
* **Use Case**: Pattern matching, string matching problems.

### **3. Important String Algorithms**

#### **a) Longest Palindromic Substring (Expand Around Center)**

A very common problem where you are asked to find the longest palindromic substring in a given string.

* **Time Complexity**: O(n^2) (though there are faster solutions like Manacher's Algorithm).
* **Example**:

  * **Longest Palindromic Substring** (LeetCode #5)

#### **b) Longest Common Substring**

This involves finding the longest contiguous sequence of characters that appear in both strings.

* **Time Complexity**: O(n\*m) (where n and m are the lengths of the two strings).
* **Example**:

  * **Longest Common Substring** (LeetCode #718)

#### **c) String Matching with Wildcards**

Use **backtracking** or **dynamic programming** for string matching where the pattern can contain special characters (like `*` or `?`).

* **Example**:

  * **Wildcard Matching** (LeetCode #44)

#### **d) String Permutation / Anagram**

This involves checking if one string is a permutation (anagram) of another.

* **Time Complexity**: O(n)
* **Example**:

  * **Valid Anagram** (LeetCode #242)
  * **Find All Anagrams in a String** (LeetCode #438)
